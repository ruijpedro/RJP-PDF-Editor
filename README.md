# RJP PDF Editor V1.2

Editor PDF para GitHub Pages.

- Abre o PDF real com PDF.js.
- Preserva as páginas originais ao guardar (não rasteriza o documento).
- Edita campos AcroForm existentes.
- Adiciona novos campos de texto RJP diretamente na página.
- Os novos textos ficam como campos PDF e podem ser reabertos e alterados.
- Guardar / Guardar como.
- Ditado no navegador ou Gboard.
- Inclui a Ficha de Atendimento como modelo base.

Nota: texto estático de um PDF arbitrário não é convertido automaticamente em texto de Word. Para o alterar, use Adicionar texto/campos; a evolução seguinte será seleção e substituição visual de texto estático.

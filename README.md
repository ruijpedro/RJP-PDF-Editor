# RJP PDF Editor V1.7

Editor PDF genérico, sem documentos incorporados.

- Abre PDFs pelo seletor, File System Access API (quando suportada) ou arrastar/largar.
- Edita campos AcroForm existentes.
- `Editar texto`: clicar em texto do PDF cria uma substituição editável persistente.
- `Adicionar`: cria novo texto editável.
- Move, redimensiona, duplica e apaga campos RJP.
- Guarda sem rasterizar as páginas.
- Reabre o PDF guardado mantendo os campos RJP editáveis.

PDFs protegidos por palavra-passe devem ser desprotegidos antes da edição.
